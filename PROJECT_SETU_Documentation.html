🏛️ 1. Executive Summary & Mission

PROJECT SETU (Smart E-Governance & Transparency Unit) is an enterprise digital public infrastructure (DPI) platform engineered to bridge the gap between citizens, municipal field officers, department directors, and state administrators. Built strictly according to Government of India digital standards, it delivers automated grievance triaging, public service fulfillment, welfare scheme discovery, and transparent SLA oversight.

🏗️ 2. System Architecture & Tech Stack

Frontend Architecture React 18 + Vite

Modern single-page application with TypeScript, Tailwind CSS, Lucide icons, and reactive i18next language engine.

Backend REST Engine Node.js + Express

High-performance TypeScript REST API server with JWT authentication, role-based access control, and secure file handling.

Database & ORM PostgreSQL 14+ / Prisma

Relational database storing citizen accounts, master taxonomy, grievances, applications, SLA timelines, and tamper-evident audit ledgers.

AI & NLP Intelligence FastAPI Microservice

Natural Language Processing model performing automated department routing, priority calculation, and anomaly surge detection.

⚡ 5. Key Platform Feature Modules

📍 Geotagged Grievance Redressal
  • Automated browser GPS auto-detection with ±meter accuracy.
  • Instant camera & photo evidence upload (up to 10MB).
  • 8-stage chronological redressal timeline with SLA countdown.
📝 7-Step Service Application Wizard
  • Direct apply for Piped Water, Smart Meters, Income Certificates, etc.
  • Applicant identity, statutory enclosures, and pre-audit checklists.
  • Instant official tracking reference generation (e.g. APP-2026-001).
🎯 Schemes & Eligibility Evaluator
  • Repository of PM-KISAN, Ayushman Bharat, PMAY, SVANidhi, etc.
  • 60-second rules-based eligibility checker matching age, income & land.
  • Direct routing to official government portals.
🤖 SETU AI Assistant (Navigator)
  • Verified floating AI government navigator in all 12 languages.
  • Pre-populates application forms and generates document checklists.
  • Live querying against official municipal service knowledge bases.
